# MutualFundAnalytics

A Python-based Mutual Fund Analytics project that fetches and analyzes NAV (Net Asset Value) data.

## Project Structure

```
MutualFundAnalytics/
│
├── data/
│   └── raw/
│       └── nav_data.csv
│
├── data_ingestion.py
├── live-nav-fetch.py
├── day1_summary.txt
├── requirements.txt
└── README.md
```

## Features

- Fetches Mutual Fund NAV data
- Stores data in CSV format
- Performs basic data quality checks
- Detects missing values
- Generates summary reports
- Uses Git and GitHub for version control

## Technologies Used

- Python
- Pandas
- Requests
- Git
- GitHub
